# 运行时数据

本目录中的成语词表、拼音覆盖表和解释索引均由项目根目录的 `data/idioms.jsonl` 生成，不应直接修改。

运行 `pnpm data:build` 重新生成，运行 `pnpm data:check` 检查所有派生数据是否一致。

原始数据整理自 https://github.com/pwxcoo/chinese-xinhua/blob/master/data/idiom.json 。
